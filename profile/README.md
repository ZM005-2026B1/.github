# Welkom bij ZM005-2026B1

Dit is de GitHub-organisatie van **Zelfstandig Multimedia 005** (2026–2027, blok 1). Voor
iedere opdracht krijg je hier een **eigen, privé repository**. Alleen jij en
je docenten kunnen die zien — je medestudenten niet.

## 📁 Mijn repositories

👉 **[Bekijk mijn repositories](https://github.com/orgs/ZM005-2026B1/repositories)**
(of klik bovenaan deze pagina op het tabblad **Repositories**).

Je ziet daar alleen de repositories waar jij toegang toe hebt. Ze heten altijd:

```
<opdracht>-<jouw-github-username>
```

Bijvoorbeeld: `hello-world-` gevolgd door je eigen username.

## 🔍 Ik zie mijn repository niet

Loop deze punten na voordat je contact opneemt:

1. **Juiste account?** Je moet ingelogd zijn met het GitHub-account dat je bij
   de aanmelding hebt opgegeven.
2. **Uitnodiging geaccepteerd?** Je hebt per e-mail een uitnodiging voor deze
   organisatie gekregen. Nog niet geaccepteerd? Kijk in je mail of op
   [github.com/notifications](https://github.com/notifications).
3. **Staat de opdracht al open?** Een repository verschijnt pas nadat je docent
   de opdracht heeft uitgezet.
4. **Two-factor authentication (2FA)** moet ingeschakeld zijn op je
   GitHub-account, anders kun je geen lid worden van de organisatie.
   → [2FA instellen](https://docs.github.com/authentication/securing-your-account-with-two-factor-authentication-2fa)

Werkt het daarna nog steeds niet, of is er iets anders niet beschikbaar?
**Neem contact op met je vakdocent** via de gebruikelijke kanalen van de
opleiding.

## 📤 Inleveren

De precieze instructies staan in de `README.md` van elke opdracht-repository.
In het kort:

1. Maak een branch **`gh-pages`** en push je werk daarnaartoe.
2. Controleer je werk via de **GitHub Pages URL** van je repository.
3. Open een **pull request** naar `main`, kies je docent als **reviewer** en
   zet de GitHub Pages URL in de omschrijving.
4. **Merge de pull request niet zelf.** Mergen betekent goedkeuring door de
   reviewer.

## 📜 Spelregels

- Werk **alleen in je eigen repository**. Maak geen kopieën of forks buiten
  deze organisatie.
- Zet je repository **niet op public** en deel je werk niet met medestudenten.
- Commit **geen wachtwoorden, API-keys of persoonsgegevens**.
- Commit regelmatig met duidelijke commit messages — dat helpt je docent én
  jezelf.
- Verkeerde branch, te veel pull requests, of helemaal vastgelopen? Meld het
  bij je docent; die kan je repository **terugzetten naar de startcode**
  (let op: je werk in die repository gaat dan verloren).

## 🗄️ Bewaar je werk

Aan het einde van het blok of studiejaar worden de opdracht-repositories
**opgeruimd**. Wil je je werk bewaren? **Clone of download je repository**
zelf vóór die tijd.
